# ☕ Telegram-магазин с корзиной и приёмом заказов

Бот-магазин: клиент выбирает товары из каталога, собирает корзину и оформляет заказ с доставкой или самовывозом. Владелец получает заказы в Telegram и ведёт их по статусам.

## Возможности

**Для покупателя**
- Каталог по категориям, карточка товара с описанием и ценой
- Выбор количества кнопками ➖ / ➕ прямо в карточке
- Корзина: изменение количества, удаление, очистка, итоговая сумма
- Подсказка «до бесплатной доставки осталось N ₽»
- Оформление: имя → телефон (одной кнопкой) → доставка или самовывоз → адрес → комментарий → подтверждение
- «Мои заказы» со статусами
- Уведомления при каждой смене статуса заказа

**Для владельца** (`/admin`)
- Мгновенное уведомление о новом заказе с кнопкой «Открыть»
- Списки заказов: новые / в работе / завершённые
- Смена статуса в один клик: принят → собирается → в доставке → выполнен (или отменён)
- Управление наличием: скрыть закончившийся товар из каталога и вернуть обратно

**Надёжность**
- Цена и название товара сохраняются в заказе: изменения каталога не влияют на старые заказы
- Товары, которые закончились, остаются в корзине с пометкой и не попадают в заказ
- Кнопки меню работают на любом шаге оформления, ничего не «зависает»

## Стек

Python 3.8+ · aiogram 3 · SQLite (aiosqlite) · FSM

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_ID`.
5. Запустите:
   ```bash
   python bot.py
   ```

При первом запуске создаётся база `shop.db` с демо-каталогом из `seed.py`.

## Структура

```
bot.py               — точка входа
config.py            — настройки магазина: название, доставка, статусы
seed.py              — демо-каталог (категории и товары)
database.py          — работа с SQLite
keyboards.py         — все клавиатуры
utils.py             — форматирование цен и заказов
handlers/shop.py     — каталог, корзина, мои заказы
handlers/checkout.py — оформление заказа
handlers/admin.py    — панель администратора
```

## Адаптация под заказчика

- Название, контакты, стоимость доставки — `config.py`
- Товары и категории — `seed.py` (до первого запуска) или прямо в базе
